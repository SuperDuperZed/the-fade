# The Fade

A press-and-hold emotional experience. Touch the screen and hold on as atmospheric text phases unfold around you. Release whenever you want to see what your patience reveals about you.

**[Live Demo](https://superduperzed.github.io/the-fade/)**

## How It Works

Open the link, follow the on-screen instructions, and interact with it. Each experience is a single self-contained HTML file with no dependencies beyond Google Fonts.

## Tech

- Pure HTML + CSS + vanilla JavaScript
- No build step, no frameworks, no dependencies
- Single `index.html` file
- Dark theme, mobile-friendly, touch support
